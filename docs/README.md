# Documentation du Blog des Lauréats

Ce dossier regroupe les documents de cadrage, d'analyse, d'architecture, de
conception et de suivi du projet **Blog des Lauréats**.

## Présentation du projet

Le Blog des Lauréats est une plateforme web destinée à valoriser les parcours,
les expériences et les réalisations des lauréats de l'EFP, avec
l'accompagnement de Solicode Tanger.

La documentation accompagne le développement du projet selon une organisation
Scrum et permet de conserver les décisions fonctionnelles, techniques et
organisationnelles.

## Organisation des documents

### Cadrage

Le dossier [`cadrage/`](./cadrage/) contient les documents qui définissent la
vision, les objectifs, le périmètre et les parties prenantes du projet.

- [`note-cadrage.md`](./cadrage/note-cadrage.md) : présentation du projet,
  objectifs SMART, périmètre, parties prenantes et risques.
- [`stack-technique.md`](./cadrage/stack-technique.md) : exigences techniques
  et justification des choix de backend, base de données, frontend et tests.

### Analyse

Le dossier [`analyse/`](./analyse/) regroupe les études et analyses
fonctionnelles du besoin.

### Architecture

Le dossier [`architecture/`](./architecture/) contient les choix
d'architecture, les principes techniques et les modèles associés.

### Conception

Le dossier [`conception/`](./conception/) rassemble les éléments de conception
fonctionnelle et technique de la solution.

### Produit

Le dossier [`produit/`](./produit/) contient les informations relatives au
produit, à ses fonctionnalités et à sa priorisation.

## Documents associés

## Conventions de contribution

- Rédiger les documents en français professionnel.
- Utiliser Markdown pour les documents textuels.
- Ajouter des liens relatifs entre les documents du dépôt.
- Mettre à jour les documents concernés lorsqu'une décision ou un périmètre
  évolue.
